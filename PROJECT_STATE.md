## УТВЕРЖДЁННЫЕ РЕШЕНИЯ

### Первая целевая платформа — Яндекс Игры
- Первая публикационная платформа: **Яндекс Игры**.
- Целевые устройства первой версии: **desktop web + mobile web**.
- Проектный чек-лист: https://docs.google.com/document/d/178naOqz-653IDVP9iFJ3P2mRbAZ3T1tM4nf4xeAPAwI/edit?usp=drivesdk
- Распакованный размер сборки по рабочему чек-листу: **≤100 МБ**.
- SDK Яндекс Игр, адаптивность, пауза, Web Audio, сохранения и локализация закладываются с начала разработки.
- Desktop: мышь, корректный resize, отсутствие системного выделения/context menu в игровом поле.
- Mobile: touch, корректная ориентация/resize, защита от longtap/callout/system scroll.
- Звук и игровой процесс останавливаются при background и fullscreen/rewarded рекламе.
- Rewarded Video — только добровольно; награда выдаётся только после подтверждённого просмотра.
- Язык определяется через SDK; локализация проектируется заранее.
- Сохранение прогресса должно переживать reload, resize/поворот и возврат после рекламы.
- Перед публикацией требования повторно сверяются с актуальной документацией Яндекс Игр; чек-лист имеет версию 15.09.2026.


### Визуальная концепция
- Игровое поле выглядит как прозрачный аквариум.
- Подготовлены сетки 8×8 и 7×7.
- Предусмотрены горизонтальный и вертикальный форматы.
- Рыбы слегка плавают внутри клетки; хвост и плавники меняют положение.
- Перестановка выглядит как переплывание в соседнюю клетку.
- Падение новых элементов должно ощущаться как движение в воде.
- Общий темп анимаций чуть спокойнее обычных match-3.
- Разрешены разные виды рыб, не только вуалехвосты.
- Будут разные карты/подводные локации.

### Живой фон
- Полноценное видео для фона не использовать.
- База: статичный фон + лёгкие анимируемые слои.
- Фоновые рыбы/стайки — tween по траекториям.
- Пузырьки — Particle Emitter из одного базового PNG.
- Водоросли — лёгкий rotation/scale tween либо 2–3 кадра.
- Блики/каустика — один прозрачный overlay/tile 512–1024 px с медленным смещением и alpha.
- Вариации scale/speed/alpha/flip используются для повторного применения ассетов.

### Пузырь/клетка
- Деформацию делать программно.
- Ориентир: scaleX/scaleY ±2–4%, Sine easing, разные фазы у соседних клеток.
- Рыба и пузырь анимируются раздельно.
- При движении допускается краткое сжатие линзы по направлению хода.

### FX
Программно:
- перемещение и падение;
- scale/fade/tint;
- подсветка совпадений;
- сияние;
- вспышки;
- частицы;
- фоновые пузырьки;
- водяные блики;
- покачивание растений;
- вращение/пульсация;
- затемнение/shake;
- массовое размножение наград.

Базовые прозрачные ассеты:
- пузырь;
- 1–2 искры;
- водяное кольцо/рябь;
- капли/брызги;
- монета;
- жемчужина;
- изображения спецфишек/бустеров.

Правило: не делать тяжёлую покадровую анимацию там, где тот же эффект можно собрать из 1–3 спрайтов + tween/particles.

### Память
- Большие текстуры загружать по текущему миру/локации.
- При переходе старые крупные текстуры выгружать.
- Не держать все миры одновременно в памяти.
